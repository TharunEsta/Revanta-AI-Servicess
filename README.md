# Revanta AI Services

Premium static website for a tech company specializing in custom websites, software solutions, AI automation, and full-stack product development.

## Run locally

Run the local server:

```bash
npm run dev
```

Then open `http://localhost:3000`.

## Deployment

Ready for static hosting.

For private quote delivery without SMTP:

1. Deploy on Netlify.
2. Enable form notifications for `quote-request`.
3. Set the notification email to `estatharun@gmail.com` in Netlify settings.
4. The email stays private and is not shown on the website.
5. Submissions redirect to `thank-you.html` after the form is sent.
